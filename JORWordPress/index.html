Putting one on a WordPress site

  1. Appearance → Themes → Add New → Upload Theme: the theme zip. Activate it.
  2. Tools → Import → WordPress (install the importer when asked): the content file (unzip it first). Assign the pages to an existing user and tick "Download and import file attachments" to copy the pictures in.
  3. Settings → Permalinks: "Post name". Settings → Reading: a static page, "Joe O'Reilly Ireland DMC" (the one called home) as the homepage. (The theme sets both when it is switched on, if the pages are already there.)
